# Machine Learning Application Using Docker

## Introduction
Docker is used to package and run applications in containers.

## Objectives
- Create Dockerfile.
- Package ML application.
- Build Docker images.
- Run containers.
- Test containerized applications.

## Tools Used
- Python
- Docker
- GitHub
- Scikit-learn

## Procedure
1. Created ML application.
2. Created requirements.txt.
3. Created Dockerfile.
4. Built Docker image.
5. Executed Docker container.
6. Tested application.

## Result
Successfully built and tested a Dockerized ML application.
