# Machine Learning Application Using Docker

## Introduction
Docker is a platform used to package and run applications in containers.

## Objectives
- Create a Dockerfile.
- Package an ML application.
- Build Docker images.
- Run Docker containers.
- Test the containerized application.

## Tools Used
- Python
- Docker
- GitHub
- Scikit-learn

## Procedure
1. Created an ML application using Python.
2. Created requirements.txt.
3. Created a Dockerfile.
4. Built the Docker image.
5. Ran the Docker container.
6. Tested the application.

## Result
Successfully created and tested a Docker-based ML application.
